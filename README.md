# VectorShift HubSpot Integration System

📌 **Overview**

VectorShift HubSpot Integration System is a robust OAuth2-based solution designed to seamlessly connect HubSpot CRM with the VectorShift platform. This technical assessment demonstrates secure authentication, efficient data retrieval, and scalable architecture patterns for enterprise integrations.

Built with **FastAPI** for the backend and **React** for the frontend, this system enables real-time CRM data synchronization and provides a foundation for expanding to additional third-party services.

---

## 🚀 Features

✅ **OAuth2 Authentication** - Secure HubSpot authorization flow  
✅ **CRM Contact Retrieval** - Fetches and displays contact data from HubSpot  
✅ **Modular Architecture** - Easy to extend with additional integrations  
✅ **Secure Token Management** - Redis-based credential storage with expiration  
✅ **Console-Based Output** - Detailed contact information logged to terminal  
✅ **IntegrationItem Mapping** - Standardized data structure across platforms  
✅ **Error Handling** - Comprehensive exception management and logging  

---

## 🛠 Technology Stack

### Frontend
- **React** - Component-based UI framework
- **Material-UI** - Modern, responsive design components
- **Axios** - HTTP client for API communication

### Backend
- **FastAPI** - High-performance Python web framework
- **Python 3.8+** - Core backend language
- **Redis** - Token and state management
- **httpx** - Async HTTP client for external API calls

### Authentication & APIs
- **OAuth2 Protocol** - Industry-standard secure authorization
- **HubSpot CRM API v3** - Contact, company, and deal data access
